# Yuan Manuscript Demo Code

## Folders

**Data_analysis_code**: MATLAB code for all behavioral and neural data analyses (except those listed below).
Within this folder, `SF_analysis_demo` serves as the main wrapper script, which calls and organizes all analysis functions.

**CEBRA-social-foraging-master**: Python code and example data for analyzing partner position representations using CEBRA (Fig. 5l-o).

**MAIRL_foraging_demo-main**: Python code and demo data for multi-agent inverse reinforcement learning modeling and analysis (Fig. 6, Sup Fig. 7).

**MARLAX-main**: Python code for multi-agent reinforcement learning simulation (Fig. 2u-v, Sup Fig. 2f-j).
